# ClawSense v0.2.0-preview.12

2026-11-03（Asia/Shanghai）。本版按用户要求保存当前开发成果，包含尚未完成验收的功能，以 GitHub Pre-release 发布。P1／P2 不因此视为整体验收通过；旧日期的验收证据保持原范围。

## 下载内容

- `clawsense-0.2.0-preview.12.tgz`：编译后的 Host、OpenClaw 插件、跨 Agent 连接器及 Live 服务脚本。
- `ClawSense-Live-0.3.12.apk`：Android 实验客户端，包名 `ai.openclaw.clawsense.livepreview`，versionCode 16，使用开发签名；需要 Android 10 或更新版本。这不是应用商店正式签名版。
- `ClawSense-v0.2.0-preview.12-source.zip`：本次源码快照，包括未验证实现、测试、方案及日期验收记录。GitHub 标签的源码归档也可使用。
- `SHA256SUMS` 与 `release-manifest.json`：资产校验值、构建版本、源码提交及检查范围。

安装包不包含个人录音、图片、配对资料、访问凭据、私有运行目录或模型权重。模型和运行依赖需另行准备，不是装一个 APK 即可独立运行的手机 Agent。

## 功能范围

- Android 配对、音频／图片／短视频采集与传输，既有 OpenClaw 入口。
- 独立伴随服务、MCP／Agent 安装配置、来源关联记忆、更正、工作交接、成果复核及复用。
- 主手机数字输入、OCR／裁剪／遮挡、联系人关联、资料缓存及桌面主动导入等 P2 实现。
- 旧 Live 与可选的 Pipecat／官方 SmallWebRTC「Live 对照版」，含当前画面、记忆上下文、停止和会话释放。

不同宿主的配置生成不等于每个品牌已实测；实际范围见[支持矩阵](../pilot/support-matrix.json)。本版保存所有上述实现，不声称每项均达到稳定使用标准。

## 安装

电脑需要 Node.js 22.12 或更新版本。在新的目录安装下载的服务端包：

```sh
npm install /absolute/path/clawsense-0.2.0-preview.12.tgz
./node_modules/.bin/clawsense --help
```

不依赖 npm 公共注册表已发布 ClawSense。OpenClaw 用户可以使用其本地插件包安装入口；其它 Agent 按 `clawsense connect` 生成指引，并结合自己的宿主版本配置。

手机侧安装随附 APK；原 `ClawSense Dev` 与此独立包名可并存。若现有同包名应用签名不一致，先导出或备份资料，再自行决定迁移方式，不要为安装而直接清空原资料。

基础 Live 当前采用 Android＋已配置本地模型的电脑，自有 Mac 负责识别、理解与合成。准备方法见[内测使用手册](../pilot/README.md)；其中较早包名应替换为本版下载文件。Pipecat 新入口的独立目录、启动方式及网络要求见[运行约定](../contracts/live-upstream-v1.md)。配置和数据目录不能由两个服务同时写入。

## 未完成与已知问题

- Live 最终真人自然度、真实回声、实物视觉和完整设备组合尚未集中签核；冷启动、响应长尾及语音停止仍有待改善。保留已有约 14.6 秒模型准备样本和约 718 毫秒生成语音停止样本，不将其描述为达标性能。
- 对照版当前为前台实验入口，每次会话最多两分钟，离开页面即结束；它是验证限制，不代表最终产品形态。
- SDK 即使不发布音轨，也曾触发系统麦克风访问。该自动测试已增加系统权限前置保护，后续自动准备改走不创建媒体连接的 HTTP 路径。详见[真机续验](../validation/p1-upstream-device-2026-10-29.md)。
- 新 Pipecat 入口的语音派发外部 Agent 工作尚未完整迁入；原工作入口保留。
- 火山 RTC／Seeduplex、强云端模型及其它云端 Live 方案是后续研究方向，本版没有新增这些供应商驱动。既有 Agent 或分析配置仍可能按用户配置调用外部模型。
- 纯手机完整模型推理、手表产品、全部宿主兼容、公开市场分发与新用户独立安装体验尚未完成。此次 GitHub 快照发布不等于启动公开招募。
