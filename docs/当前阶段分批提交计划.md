真机验收重点：

- 自动视频默认关闭时，即使 Host 下发 directive，也不能录制。

- 服务端 503 / analysis queue 高水位时，Android 应拉长图片采样间隔、延后低信号音频、跳过自动视频 directive。
- 如果真实拥堵难复现，可用 debug APK 的 `scripts/check-android-live.sh inject-throttle 60000 24` 辅助验证端侧节流；报告必须明确它是 debug 注入，不等同真实服务端压测。
