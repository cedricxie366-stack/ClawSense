# ClawSense 多 Agent 第三轮具体任务单

这份任务单用于启动当前最关键的一轮工作：从“链路已通”推进到“语义质量更好、普通聊天也能正式接进 ClawSense 回顾能力”。

当前阶段判断：

- Android 真机采集、图片上传、音频上传、心跳都已跑通
- 媒体库独立轻量页已跑通：
  - `/plugins/clawsense/library`
- `openclaw clawsense review today` 已可用
- 当前主要问题不是“有没有功能”，而是：
  - 音频真实 STT 仍然经常失败
  - 图片视觉摘要仍然经常失败
  - 普通聊天页还没有通过明确的 ClawSense skill / tool 接进回顾能力
  - 长对话录音切片过碎，影响模型理解

## 本轮总目标

1. 把图片和音频从“可读降级”推进到“更高概率真实有语义”
2. 把长对话切片策略从“15 秒保守片段”推进到“更适合回顾的连续会话窗口”
3. 给普通聊天页一个明确的 `ClawSense` skill / tool 入口，让 OpenClaw 能基于 ClawSense 的事件索引和原件能力回答：
   - “总结过去一个小时我需要注意的地方”
   - “回顾今天发生了什么”
4. 不引入视频，不重写当前 ingest 数据面，不做新的重型 Web 产品

## 统一边界

所有 agent 都必须遵守：

- 不要把当前数据面整体替换成官方 Android Companion / node 协议
- 不要依赖 ClawSense 官方公网域名
- 媒体库和回顾能力默认复用用户当前 OpenClaw 的同一地址
- 不要把普通聊天页“直接读任意文件系统”当成默认方案
- 聊天页接入 ClawSense 的正确方式是：
  - 明确 skill / tool
  - 通过 ClawSense 的事件索引、review、受控 artifact 读取能力来取数
  - 如果涉及文件读取，也必须仅限 ClawSense 管理的媒体根目录

- `/Users/cedric/Documents/ClawSense/src/state-store.ts`

- 明确区分：
  - provider 不可用
  - provider 可用但返回空
  - 输入片段过短 / 低信号
  - 文件格式 / MIME 问题

优先文件：

- `/Users/cedric/Documents/ClawSense/index.ts`
- `/Users/cedric/Documents/ClawSense/src/memory-store.ts`
- `/Users/cedric/Documents/ClawSense/src/openai-client.ts`
- `/Users/cedric/Documents/ClawSense/src/utils.ts`
- `/Users/cedric/Documents/ClawSense/test/memory-store.test.ts`

验收标准：

- 新采集的清晰 5 到 10 秒中文语音，不应普遍继续只落成降级摘要
- 如果仍失败，必须能明确区分失败类别

#### Task B3-2: 图片视觉摘要真实失败根因排查与修复

目标：

- 找出为什么图片大量落成 `visual summary unavailable`
- 尽量提升真实视觉摘要成功率

要求：

- 优先查：
  - 当前视觉 provider 是否真的支持图片输入
  - 请求格式 / 输入形式是否正确
  - 超时 / 响应解析 / prompt 失败点
- 保持失败可降级，但不要只停在降级

优先文件：

- `/Users/cedric/Documents/ClawSense/index.ts`
- `/Users/cedric/Documents/ClawSense/src/memory-store.ts`
- `/Users/cedric/Documents/ClawSense/src/openai-client.ts`
- `/Users/cedric/Documents/ClawSense/test/memory-store.test.ts`

验收标准：

- 新采集的清晰图片，不应普遍继续落成 unavailable 占位

#### Task B3-3: 普通聊天页接入 ClawSense 的明确 tool / data access

目标：

- 给 OpenClaw 的普通聊天能力增加一个明确的 `ClawSense` 取数入口
- 让聊天页可以通过 skill / tool 读取 ClawSense 的事件索引和受控原件信息

要求：

  - 读 `DailyReview`

  - 读受控 artifact 元数据与可访问原件
- 如确需读文件，只允许读：
  - `~/.openclaw/plugins/clawsense/media/...`
- 输出至少支持这些问题：
  - “总结过去一个小时我需要注意的地方”
  - “回顾今天发生了什么”
  - “最近有没有值得我回看的图片或对话”

优先文件：

- `/Users/cedric/Documents/ClawSense/index.ts`
- `/Users/cedric/Documents/ClawSense/src/http.ts`
- `/Users/cedric/Documents/ClawSense/src/review-engine.ts`
- `/Users/cedric/Documents/ClawSense/src/state-store.ts`
- `/Users/cedric/Documents/ClawSense/src/openclaw-types.ts`

验收标准：

- 聊天页可通过明确 tool / skill 访问 ClawSense 数据
- 不需要模型自己“猜着去看文件系统”
- 不破坏当前媒体库和 review 命令
