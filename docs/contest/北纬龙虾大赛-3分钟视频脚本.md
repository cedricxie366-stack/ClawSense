# ClawSense 3 分钟视频脚本

目标：

- 控制在 `2 分 40 秒 - 2 分 55 秒`
- 讲清楚问题、方案、Demo、价值、安全边界
- 对齐评审最关心的四件事：`创新`、`技术`、`应用前景`、`Demo`

## 拍摄建议

建议素材组合：

- 手机实拍：旧 Android 手机、扫码配对、启动服务
- 屏幕录制：OpenClaw 侧媒体库、CLI、Daily Review
- 辅助动画：一张简单的数据流动效

建议节奏：

- 前 30 秒抓住问题
- 中间 90 秒展示真实链路
- 最后 30 秒讲价值和安全边界

## 分镜脚本

### 0:00 - 0:15

画面：

- 快切镜头：旧手机放在桌面上、会议片段、聊天记录、碎片信息
- 字幕浮现：`AI Agent 会回答，但常常记不住今天发生了什么`

旁白：

`今天的大多数 AI Agent 都很会对话，但它们缺少一双能持续感知现实世界的眼睛和耳朵。很多重要信息，根本不会出现在聊天框里。`

### 0:15 - 0:35

画面：

- 展示旧 Android 手机
- 屏幕上出现 ClawSense 标识与 OpenClaw 字样
- 图示从“旧手机”流向“AI Agent”

旁白：

`ClawSense 想做的，就是把一部闲置的旧 Android 手机，变成 OpenClaw 的全天候感知节点。它持续采集关键音频、图片和心跳，把原本会消失的上下文保存下来。`

### 0:35 - 0:55

画面：

- 手机扫码配对
- App 中显示已配对、启动服务
- UI 上出现“运行中”

旁白：

`用户只需要完成一次扫码配对，旧手机就可以开始工作。ClawSense Android 客户端负责采集，OpenClaw 插件负责接收、索引和总结。`

### 0:55 - 1:20

画面：

- 手机界面展示权限与状态
- 动画说明音频触发上传、图片定时上传、心跳回传
- 叠加文字：`音频 VAD`、`60 秒基线快照`、`活跃窗口 10 秒快照`

旁白：

`在运行过程中，手机会用 VAD 检测声音片段并上传音频，默认每 60 秒上传一张图片；一旦进入对话活跃窗口，图片频率会临时提升到每 10 秒一张。系统同时持续发送心跳，确保设备在线可见。`

### 1:20 - 1:45

画面：

- 切到服务端媒体库
- 展示按日期、设备查看音频和图片
- 鼠标点击当天素材

旁白：

`上传后的原始素材会进入 ClawSense 的媒体库。我们不是把它们简单堆在一起，而是先按事件窗口归并，再让多模态模型只分析关键片段。这样上下文更干净，成本也更可控。`

### 1:45 - 2:10

画面：

- 终端或页面运行 `openclaw clawsense review today`
- 显示 `Today at a glance`、时间线、关键人物、关键主题、明日建议

旁白：

`最终，用户得到的不只是原始素材，而是一份面向助手式使用的 Daily Review。它会告诉你今天发生了什么、有哪些关键人物和项目、哪些细节值得追问，以及明天应该继续关注什么。`

### 2:10 - 2:30

画面：

- 列出 3 个关键词：`旧机复用`、`事件索引`、`助理式回顾`
- 搭配系统结构图和实际界面

旁白：

`ClawSense 的创新点有三个。第一，旧手机复用，部署成本低。第二，强调事件索引，而不是素材堆积。第三，从原始感知一直打通到 Daily Review，让 AI Agent 真正开始拥有“今天的记忆”。`

### 2:30 - 2:48

画面：

- 展示安全标签：`权限明确`、`边界可控`、`同源访问`
- UI 中显示服务状态、降级模式、媒体库入口

旁白：

`我们也非常重视安全与责任使用。ClawSense 强调明确权限、透明状态、同源访问和边界可控。视频只作为用户可控的短片段证据增强，不做全天连续录像，也不做微表情和内在意图自动判断。`

### 2:48 - 2:58

画面：

- 回到主视觉，手机与 Daily Review 面板同框
- 打出项目名和一句话总结

旁白：

`ClawSense 不是再做一个聊天机器人，而是给 AI Agent 一套低成本、持续、可信的现实世界感知入口。谢谢大家。`

## 结尾字幕建议

`ClawSense`

副标题：

`把旧 Android 手机变成 OpenClaw 的全天候感知节点`

底部短句：

`持续感知 · 事件索引 · Daily Review`

## 如果你只能做“纯录屏版”

可以按下面顺序录：

1. 打开 Android App，展示已配对和运行中状态
2. 做一次简短说话测试
3. 打开媒体库，展示新素材出现
4. 运行 `openclaw clawsense review today`
5. 收尾放一页总结 PPT

即使没有复杂拍摄，也能把主链路讲清楚。
