如果你还有补交流程或邮件补交窗口，这份目录里的材料可以直接继续用；如果已经不能提交，也适合作为路演、作品集或后续投递版本。

## 2. 为什么推荐报“生产力龙虾”

ClawSense 更适合被包装为“让 AI Agent 获得连续感知与日回顾能力的效率引擎”，原因有三点：

- 它不是单次问答工具，而是持续采集音频、图片和心跳，再形成可回看的上下文与日回顾
- 它强调“一部旧手机 + 一个 Agent = 更强的个人工作流”
- 它已经具备配对、上传、媒体库、Daily Review 这些可演示链路，比较适合在评审里体现“创新 + 技术 + Demo”

如果你更想突出“陪伴、记事、照护、生活整理”，也可以把文案轻量改成“生活龙虾”版本，但默认建议先用生产力叙事。

## 4. 建议提交口径

项目名建议统一为：

`ClawSense：把旧 Android 手机变成 OpenClaw 的全天候感知节点`

一句话介绍建议统一为：

`ClawSense 让旧手机变成 AI Agent 的连续感知入口，把音频、图像与事件窗口组织成可回看、可总结、可追问的日常上下文。`

如果要直接填写报名表里的“你的龙虾叫什么名字 / 能做什么事”，建议用：

`ClawSense：把旧 Android 手机变成 OpenClaw 的全天候感知节点，持续采集关键音频与图像并生成 Daily Review。`

如果要填写“你的虾能干什么？解决了什么问题？效果如何？”，建议用：

`ClawSense 解决了 AI Agent 缺乏连续现实感知的问题。它复用旧 Android 手机，通过音频、图像和心跳形成事件窗口，并在 OpenClaw 上输出媒体库与 Daily Review，让用户能够回看今天发生了什么、有哪些关键人物和主题，以及明天应该继续关注什么。当前 MVP 已打通配对、上传、媒体库和回顾链路。`

## 5. 不要过度承诺的地方

为了和仓库现状保持一致，材料里建议明确这些边界：

- 当前是 `MVP / 已完成 Phase 1`，不是最终商业化成品
- 视频只作为用户可控的短片段 evidence 增强，不做全天连续录像
- 主动短视频必须默认关闭、显式开启、可解释并受队列 / 冷却 / 上限保护，不做不可关闭的“语音开启视频”
- 当前不做微表情、情绪或内在意图自动判断
- 多 provider 标准化还在继续完善

这样写更稳，也更符合报名页强调的“透明可控”和“安全负责”。
