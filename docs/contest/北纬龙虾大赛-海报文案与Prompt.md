# ClawSense 海报文案与 Prompt

这份内容分两部分：

- 可直接上海报的中文文案
- 可用于 Midjourney / Flux / SDXL 的生成提示词

建议尺寸：

- 线上提交图：`4:5` 竖版
- 路演打印版：A1 或 A2 竖版

建议主视觉方向：

- 不做“赛博紫色泛光”套模板
- 用 `深海蓝 + 海盐白 + 电子薄荷绿 + 琥珀橙` 做主色
- 主体画面是“一部旧 Android 手机 + 音频波形 + 时间轴 + Daily Review 卡片 + OpenClaw 控制界面”

## 1. 海报主文案

主标题：

`ClawSense`

副标题：

`把旧 Android 手机变成 OpenClaw 的全天候感知节点`

一句话介绍：

`持续采集音频、图像与事件窗口，生成可回看、可总结、可追问的 Daily Review。`

四个卖点短句：

- `旧手机复用，低成本部署`
- `音频 + 图片 + 心跳，连续感知`
- `事件索引，不是素材堆积`
- `Daily Review，让 Agent 真正记住今天`

底部补充文案：

- `OpenClaw Plugin + Android Client`
- `生产力龙虾赛道`
- `MVP 已跑通真实链路`

## 2. 海报版面建议

上半区：

- 项目标题
- 一句话介绍
- 一张核心主视觉图

中间区：

- 左侧放“旧手机 -> 感知 -> 事件窗口 -> Daily Review”的流程图
- 右侧放 4 个能力卡片

下半区：

- 安全与责任使用标签
- GitHub / Demo / 团队信息
- 可放一句总结口号

口号建议：

`不是再做一个聊天机器人，而是给 AI Agent 一套低成本的现实世界感知入口。`

## 4. 如果你要直接给设计师

可以把下面这段直接发给设计师：

```text
请做一张竖版项目海报，主题是 ClawSense。主视觉是一部旧 Android 手机，被重新利用为 AI Agent 的全天候感知节点。画面里要同时体现音频采集、定时拍照、事件窗口、媒体库、Daily Review 这几个层次。整体不要做廉价赛博风，要更像“可信赖的工程产品 + 有想象力的 Agent 基础设施”。颜色以深海蓝、白色、薄荷绿、暖橙为主，保留明确的标题区、卖点区和底部信息区。
```

## 5. 海报上的安全标签建议

建议在右下角放 4 个小标签：

- `权限明确`
- `边界可控`
- `同源访问`
- `旧机复用`

这样能和报名页强调的“安全、伦理与负责任使用”形成呼应。
