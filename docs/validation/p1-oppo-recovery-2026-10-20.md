# P1 OPPO 简化验收失败与修复

日期：2026-10-20。对应[现行计划](../产品演进路线与执行计划.md)的P1，延续[当日真人记录](p1-human-2026-10-20.md)。本轮不签核P1整体；P2集成预览保留，公共发布和招募继续暂缓。

## 原轮失败

OPPO PDEM10／Android0.3.6（versionCode10）、Host0.2.0-preview.6。本人反馈准备模型太久、更正被背景声打断并出现“嗯、对”等附和、第一次“停”识别成“银”、当前画面回答成文字对话界面。原轮不通过。

会话记录佐证：

- “改为周四4万元，现在是什么安排？”进入回答，但被说成安排不明确、需等对方确认。分类器将“是什么”送入一般知识问答，丢掉了会话背景。
- “我”“对”“被”等短片段进入新回答；“银”甚至被解释为金属。没有原始真人录音，不能据此确定每个片段来自背景噪声、回声或本人。
- “我现在正在看什么”“现在看什么”“请问我现在正在看的是是什么”等自然变体未命中视觉请求，普通文字模型错误猜测场景。
- 无媒体连接对照中，旧服务三次进入分别为11.03、5.70、5.44秒。每次断开立即清理准备状态；镜头开启还会在进入时加载视觉模型再释放驻留。

原始真人历史与应用日志保存在私有`.local/p1-oppo-fixes-2026-10-20/`，没有覆写旧记录或补写真人通过。

## 已实施

候选为Host0.2.0-preview.7、Android0.3.7（versionCode11），新APK已保留资料安装到OPPO。

1. 最后连接断开后保留声音准备状态60秒，随后释放缓存与驻留；重连仍检查模型进程。准备按音色和进程代次复用、保序，重新加载进程或冷却会失效。不保留采集，不在开启镜头开关时提前加载视觉模型；真正提问时按需处理。
2. 改口加追问保留前文，带问号的具体更正也保留为用户陈述。未解析的省略式更正不再让旧事实快捷回答覆盖它。复述不提升本人确认权威、不代替正式审核，表达约束减少附和、反问及无依据的交付保证。
3. “我”“被”等未成句片段不另起回答；简短附和即使在播放结束后才识别完成，也不另起一轮。单字中间识别不打断播报，明确停止口令除外。
4. 播放期间的其它含糊单字最多等待另一识别器250ms：明确识别成停止则停止；仍不清楚则暂停并在屏幕提示，不开始新话题、不自行恢复。保留原识别，不把“银”硬改成“停”。这不能证明真人短口令准确率已修复。
5. 当前画面的自然问法进入一次性拍照路径；翻译／改写所引用的问句不触发相机。没有取得新照片时明确失败，不由文字聊天猜画面。只有“详细介绍”等未说完的请求延长收句等待，避免过早切轮。

原Android ingest、OpenClaw入口、来源权限和私密处理边界保留；本轮模型运行在用户自有Mac，没有切换外部模型。
