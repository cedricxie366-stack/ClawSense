## 四项改动

| 问题 | 当前实现 | 验证边界 |
| --- | --- | --- |
| 每次开启前等待模型 | 进入 Live 页即可提前准备语音；勾选镜头时准备视觉资产，不采集。语言／TTS 懒加载并完成真实预热后才就绪；沿用按音色和进程代次复用准备结果，空闲 60 秒后冷却 | 准备后进入已很快，但后台准备本身仍有十多秒长尾，不能写成冷启动已解决 |
| 首次问画面慢、未拿到图 | 已选镜头时在就绪前加载视觉资产，真正提问才拍新图；保留两秒新鲜度及缺图明确失败。概览生成完整的首个分句后结束，细节问题另行处理 | 最终版本暗画面链路通过；有光实物的最终真人首图仍待集中检查 |
| 杯子被说成水壶并补细节 | Android 压缩前处理 EXIF 旋转／镜像，后端亦兼容带 EXIF 的输入；过暗／缺细节先说明看不清；概览聚焦主体，禁止臆测内容物、身份和关系 | 八种 EXIF 转换通过；保存的杯子照片实际模型回放见 JSON。不保证任意物体准确，也不把观察变为本人确认 |
| “停”迟到、含糊字另起回答 | Live 单独会话使用 20ms PCM；不足 Silero 窗口时保持上次判断；短口令最多六次有界核对，只认明确口令。音频在异步鉴权前保序，播放状态以最新消息为准，小包连接启用 TCP_NODELAY | 生成语音经实际手机播放器可停且不恢复；真人麦克风、扬声器回声与不同发音仍待。相近字没有被强行改为“停” |

同时减少保存快照／受管副本元数据后对无变化旧资料的重复扫描。来源、政策、身份、删除及 Live 观察写入仍完整核对；外部替换或撤权不得被元数据优化跳过。认证仍逐包检查，小型元数据检查不排队等待资料落盘；内容变化时异步合并重读并再次核对身份，失败即拒绝。

产品模型处理在用户自有 Mac（16GB）进行，没有新增云模型调用、换模型或降级音色。它仍是手机与电脑协同，不是纯手机推理或已验收的全双工。原 Android ingest 与 OpenClaw 入口保留，独立状态目录没有两个写入者。

## 测量解释与仍开放的目标

- **冷启动未完全收口。**同样声音及文字的隔离模型交替对照：原加载两次 11.45／5.82秒，懒加载两次 4.37／4.30秒；四份输出 PCM 完全相同。它证明特定模型准备收益，不代表手机端四秒启动。完整手机准备在本轮多次检查中约 6.5–17秒，最终样本13.14秒；不能只取最快值。等待从点击开启前移到进入页面后，是体验改进但没有消除计算开销。
- **首图按场景区分。**中间候选的明亮杯子样本曾返回“眼前是玻璃杯”，Host 首音约4.10秒；最终版本实景采集时环境已暗，因此最终2.11秒是暗画面拒答链路，不能当作明亮物体识图的同条件加速。保存照片回放没有手机拍摄、传输和可听声音。
- **停止目标没有更换口径。**最新手机数值从生成口令开始送入算到 `AudioTrack.pause` 完成；旧记录中“最后有声帧→停止”等边界不同，不能直接相减。3个手机样本不足以给真人 P95 下结论，而且仍有样本超过300ms。10轮CPU回放也不能替代这个目标。
- **没有声称听感通过。**本轮没有新的真人音色、改口、物体与插话回执。此前接受的三段声音只保留原范围。耳机／来电／安全锁屏及实际手机持续功耗仍按原计划独立验收，短测不覆盖这些设备组合。

## 失败和修正保留

1. 原先 128ms 音频分帧的受控停止较慢；最初20ms方案仍有278–536ms，发现 VAD 窗口不足被误当成静音后修复。所有迭代日志保留，不挑最快样本代替最终手机结果。
2. 异步鉴权延迟可使第二个音频包先到 VAD；受控测试先复现失败，再验证队列修复。延迟旧播放状态覆盖新状态也单独验证。
3. 后台 Android 准备测试被系统暂停，恢复前台后超时。测试已改为前台保持亮屏；此前失败不算通过，也不把系统暂停全部归咎模型。
4. 一次测试 PCM 传输得到空文件；修正传输方式并校验长度后重跑。EXIF测试最初要求输出标记必须为1，但实际无旋转标记为0；修正为接受0或1，同时保留实际像素方向断言。
5. 清理的只是本项目闲置构建进程，内存压力有所下降；未关闭用户其它应用，也没有证明所有长尾都由内存引起。

私有原始报告、测试照片与日志位于 `.local/p1-final-2026-10-20/`（任务开始于10月20日），不进入分发包。候选 APK／tarball、SHA-256 和首装结果放在其 `artifacts/` 中；不覆盖旧候选，不进行公共发布。机器可读结果见[同日JSON](p1-ready-2026-10-21.json)。

## 最后一轮真人检查

仅当本人方便时，做一轮约两分钟：保持镜头对准光线充足的杯子或书，依次验证新客户事实、改口后追问、当前物体、遮住镜头后的不确定回答、长答时说“停”、安静三秒不恢复、再问“六加八”。细化为十个短轮次可满足现场连续性检查；不重复旧音色试听或长文朗读。开始采集仍由本人点击，调试版从开启起最多120秒停止。

核对实际会话记录与本人回执后再决定限定模式是否通过；若停止长尾或首图仍失败，保留为工程问题，不能要求用户用反复重测代替修复。严格300ms P95和设备组合仍需对应证据。
