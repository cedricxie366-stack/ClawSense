## 本轮实现

OpenClaw 原先默认维护自己的资料库，而其它客户端连接独立伴随服务。新增可选客户端模式：`companionUrl` 与 `companionTokenFile` 同时设置时，原生 ClawSense 插件只注册 `clawsense_tools` / `clawsense_call`，通过现有受控接口读取和写入共享服务，不创建本地资料库、采集服务或第二个权威写入端。两项都未设置时，保留原 OpenClaw 数据面、配对及 CLI。

`connect openclaw` 生成配置片段与私有可撤销凭据，身份是 `openclaw-client`；不修改全局 OpenClaw 设置。片段需合并到已安装当前插件的目标环境。模型不能通过参数修改授权身份，完成工单仍受指定 Agent 和版本检查约束。适配器保留原图内容，撤销在后续请求生效，失败不报完成；请求取消不代表已接受的服务端写入已被撤回。
